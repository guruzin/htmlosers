Sobre o projeto:Projeto de uma planilha de controle de gastos desenvolvida para facilitar a organização financeira. A aplicação permite registrar receitas e despesas, acompanhar os gastos e visualizar de forma simples como o dinheiro está sendo utilizado, ajudando no planejamento e controle do orçamento.
